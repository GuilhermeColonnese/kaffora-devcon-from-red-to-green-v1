# Accessibility: values to paste

## Style Book
- Fast path: Design → Style Books → **Kaffora Accessible (WCAG AA)** → ⋮ → Mark as Default.
- With brand fonts: Design → Style Books → ⋮ → **Import** → `style-book-kaffora-brand-v2.zip` → Mark as Default (uses the fonts from the *Kaffora Brand Fonts* client extension).
- Live edit of Kaffora Brand v1: Primary `#C2107F` · Secondary `#C7C9EA` · Brand Color 1 `#FF5CCB`.
